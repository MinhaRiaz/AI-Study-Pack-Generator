# 📚 AI Study Pack Generator

An interactive, multi-stage AI application built with **Streamlit** and high-speed LLM inference engines (**Groq** / **Google Gemini**). The application converts user-specified study topics, goals, and target durations into structured, multi-section learning packs—complete with personalized study plans, detailed notes, interactive flashcards, customizable quizzes, and exam strategies.

🚀 **[Try the Live Application](https://ai-study-pack-generator-app.streamlit.app/)**

---

## 🚀 Features

### 🎯 Multi-Stage AI Pipeline
Instead of relying on a single prompt, the app executes a **5-stage sequential workflow** where each AI stage evaluates, formats, and refines output generated by the previous stage:
1. **Planning:** Creates learning objectives, time allocations, and difficulty strategy.
2. **Content Generation:** Produces detailed notes, section explanations, key points, and core terms.
3. **Assessment:** Generates targeted Multiple Choice Questions (MCQs), short answer prompts, and statement verifications.
4. **Quality Review:** Evaluates factual accuracy, pedagogical clarity, and objective alignment.
5. **Refinement:** Automatically fixes omissions or quality gaps identified in the review stage.

### 📊 Customizable Study Inputs
- **Education Level:** Beginner, Intermediate, or Advanced.
- **Flexible Timelines:** 30 minutes, 1 hour, 1 week, 2 weeks, or 1 month.
- **Goal Targeting:** Custom text area for user-specific learning goals (e.g., *Build a strong foundation and prepare for practical projects*).

### 🧩 Modular Output Sections
Users can toggle individual sections on or off according to their immediate study needs:
- 📌 **Study Plan:** Learning objectives, strategy, and time allocation.
- 📖 **Study Notes:** Broad subtopics featuring detailed explanations, key points, and examples.
- 🎴 **Flashcards:** Term and definition pairs rendered as structured study cards.
- 📝 **Assessment & Quiz:** Dynamic Multiple Choice Questions (MCQs) with interactive expandable answer keys.
- 💡 **Exam Tips:** Strategic key takeaways and quick summaries.

### 🎛️ Dynamic Quiz Controls
Custom slider allowing users to generate between **1 and 20 MCQs** tailored strictly to the generated content.

### ⚡ Real-Time Progress Visualizer
Smooth, animated progress tracking (`st.progress`) providing real-time visual feedback and stage completed messages through every step of the AI pipeline.

### 🛡️ Built-In Resilience & Retries
Configured with exponential backoff retry handling to prevent application crashes during API rate limits (`429`) or server capacity spikes (`503`).

⚙️ Installation & Local Setup
Follow these steps to run the application on your computer:

1. Clone the Repository
Open Command Prompt or Terminal and run:

Bash
git clone [https://github.com/MinhaRiaz/ai-study-pack-generator.git](https://github.com/MinhaRiaz/ai-study-pack-generator.git)
cd ai-study-pack-generator
2. Create a Virtual Environment
Windows:

DOS
python -m venv venv
venv\Scripts\activate
macOS / Linux:

Bash
python3 -m venv venv
source venv/bin/activate
3. Install Dependencies
Install all required packages using:

Bash
pip install -r requirements.txt
🔑 API Key Configuration
The application requires an API key for Groq (recommended for speed) or Google Gemini.

Streamlit Secrets (Local Development)
Create a .streamlit folder inside the project root:

Bash
mkdir .streamlit
Inside .streamlit/, create a secrets.toml file:

Ini, TOML
GROQ_API_KEY = "gsk_your_groq_api_key_here"
# OR
GEMINI_API_KEY = "your_gemini_api_key_here"
⚠️ Important: Never upload .streamlit/secrets.toml to GitHub. Ensure .gitignore includes .streamlit/secrets.toml.

▶️ Run the Application Locally
After installing dependencies and configuring your API key, start the Streamlit application:

Bash
streamlit run app.py
The application will run locally and open in your default browser at:
http://localhost:8501

📤 How to Use the Application
Step 1 — Configure Study Settings: Enter your topic, select your education level, specify duration, and write your core learning goals in the sidebar.

Step 2 — Select Sections: Check or uncheck sections (Notes, Flashcards, Quiz, Study Plan, Exam Tips) based on what you need.

Step 3 — Set Quiz Questions: Adjust the slider to pick your desired number of MCQs (1–20).

Step 4 — Generate: Click 🧪 Generate Study Pack.

Step 5 — Review Results: Track real-time progress through all 5 workflow stages, then review your generated study materials.

🔒 Privacy & Safety
Generated study materials rely on AI processing through API endpoints.

Avoid passing confidential or protected materials in prompt inputs unless you accept the applicable model provider data-handling policies.

API keys are securely managed via Streamlit Secrets and are never hardcoded into source files.
